
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Crie um jogo de adivinhação de palavras em Python, praticando listas, laços, condicionais e entrada de dados do usuário em uma aplicação interativa.

## 📝 Tarefas

### 🛠️ Estrutura do Jogo

#### Descrição
Crie o núcleo do jogo em que o usuário tenta adivinhar letras de uma palavra secreta até completar a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória a partir de uma lista pré-definida
- Exibir o estado atual da palavra com letras reveladas e espaços para letras ainda não descobertas
- Ler uma letra informada pelo usuário
- Verificar se a letra está na palavra e atualizar o progresso do jogo
- Contar as tentativas restantes e avisar o jogador quando a letra for inválida ou repetida
- Encerrar a partida quando a palavra for completamente adivinhada ou quando as tentativas acabarem

### 🛠️ Feedback de Vitória e Derrota

#### Descrição
Melhore o jogo com mensagens claras de resultado para deixar a experiência mais amigável e fácil de entender.

#### Requisitos
O programa concluído deve:

- Exibir uma mensagem de vitória quando o jogador descobrir a palavra completa
- Exibir uma mensagem de derrota quando as tentativas forem esgotadas
- Mostrar a palavra final escolhida ao término da partida
- Permitir que o jogador queira jogar novamente sem precisar reiniciar o programa manualmente
